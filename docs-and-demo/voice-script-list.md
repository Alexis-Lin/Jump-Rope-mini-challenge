# 跳绳小程序 · 语音话术总清单

> 版本 v1.0（2026-08-31）· 配套《audio-voice-strategy.md》v0.4 §4 使用
> 用途：**给程序照抄实现、给配音照单录制**。每行 = 一个触发事件：类别 + 重要性/紧迫度/冷却（仲裁引擎入参）+ 生成方式 + 全部文案变体。
> 语言：中文为主版本；英文对照以 `demo.html` 内 `I18N.en` 为唯一事实源（两处已逐条对齐，勿在本表另维护英文副本）。
> 约定：`{n}` 等花括号为模板槽位；变体 ≥2 条的事件运行时**随机选且本轮不重复**；标注「Demo✅」= 当前原型已实装该条。

紧迫系数：NOW ×1.5 / SOON ×1.0 / WHENEVER ×0.6；优先级 = importance × 系数；抢占阈值 20。
「每轮」= 单次训练 session；「限次」在 session_start 重置。

## 六、体量与录制口径

- 预生成固定条目 ≈ **190 条/语言**（数字 99 + 池 A/B/C + 各事件变体），opus 约 2.5–3MB。
- **昵称称呼音频**（9-2 拍板）：不走每日管线——用户设置/修改昵称时一次性云端生成「{昵称}，欢迎回来！」缓存复用；未写昵称/生成失败回落「欢迎回来！」。
- 动态数字/昵称/日期一律云 TTS（M1–M8、E2/E5/E8 等模板槽位），预取失败回落各事件的**无变量兜底句**（表中变体里不带槽位的那条）。
- 录制统一「元气教练」音色（= ATOM 设备昵称的声音），语速 1.05–1.1×。
- 本表新增/修改话术时**同步更新** `demo.html` 的 `I18N.zh/en` 与策略文档 §4.4，三处保持一致。
