## 1. 原则与三层音频

**原则**：像真人教练——四类话都会说（安全🛡️/进程⏱️/动作🎯/情感❤️），但**克制地只说该说的**；有记忆、有分寸、有人设。默认沉默：没到触发条件就不出声，说不出高价值的话就闭嘴。

| 层 | 内容 | 音量 | 打断关系 | 可关 |
|---|---|---|---|---|
| **L1 音效** | 计数叮（每跳，五声音阶轮转）/ 逢十重击 / 得星 / 倒计时哔 / **限时最后 10s 时钟滴答**（9-2 会议新增）/ 发令锣 / fanfare / PB 啪啪 / riser —— 新制干声 | 100% | **支持 2–3 路并行**（9-2 会议：计数叮×滴答×庆祝会挤在一起，单路必冲突；quota 制，人声路空闲可临时借用；实测防破音），永不被人声打断 | 不可关（计数确认） |
| **L2 人声** | 单一「元气教练」音色（= ATOM 的声音），单通道一次一句 | ≈90% | 高档可掐断中低档 | 设置「教练语音」 |
| **L3 BGM** | 五声音阶节奏循环，跳频自适应变速（96–128BPM，±4 量化、小节边界换挡） | ≈25%，人声时 duck −50% | 永不打断他层 | 设置「背景音乐」 |

**安静模式**（设置第 7 行一键）：关 L2+L3，只留计数音效；唯一例外——出框安全提示照播。
**课中零浮层弹窗**：一切事件反馈 = 语音 + 既有画面元素；页面级告知只用整屏遮盖模块。

### 1.1 BGM 音源方向（9-2）

变速需求决定「现拿一首歌」最不合适（time-stretch 劣化音质）：
1. **V1：端上程序化合成**（推荐）——Demo 合成器即雏形，零版权零存储、无级变速不变调；委托音效设计师打磨音色即可。
2. **V2：委托 loopable 分层母带**——五声音阶国风电子（木琴/马林巴＋电子鼓组），鼓/贝斯/旋律三层 × 96/112/128 三档；参考听感：《Ring Fit Adventure》《Jump Rope Challenge》《Wii Fit》。
3. 商用曲库（Epidemic/Artlist `playful percussion loop 110–125 BPM`）仅应急。
风格锚点：轻快打击乐为骨、少旋律多律动、无人声、可循环；热血 2 不换曲只叠高频律动层。

## 2. V1 播报清单（含全部话术）

> 触发判断全部端上本地完成。「每轮」= 单次训练；限次在开轮时重置。标 ⏸ = V1.1 候补（逐条打开），标 🚫 = V2 后置（见 §10）。

### 2.1 流程与节奏 ⏱️

| 事件 | 触发 | 话术 |
|---|---|---|
| 发令 | 点开始 → 倒计时 | 三 / 二 / 一 / **Body Park！**（品牌声，固定音频） |
| 模式提示 | 进模式选择页 | 「选择模式：不限时自由跳，或者限时挑战」 |
| ⏸ 模式页久留 | 模式选择页停留 ~20s 无操作（9-2 会议提议，候补） | 轻提示一句，如「选好模式就出发吧！」 |
| 整十报数 | 每逢 10 下 | 「五十」「一百二」…（固定音频 10–990 共 99 条；≥1000 只报整百；被高档压过即丢弃） |
| 报时 | 自由跳每满 1 分钟 | 「已经跳了 {m} 分钟啦」（数字拼接；第 20 分钟让位长轮关怀、第 29 分钟起让位上限预告；**停跳中不报**） |
| 限时节点 | 剩 30s / 最后 10s | 「还有三十秒」／「最后十秒，冲刺！」＋**最后 10s 时钟滴答音效持续到归零**（9-2 会议拍板，与计数叮并行不互斥） |
| 时间到 | 限时读秒归零 | 「时间到！{m} 分钟 {c} 下{，体测评级{r}}，辛苦啦」 |
| 上限预告 | 自由跳第 29 分钟 | 「还有一分钟到三十分钟上限，冲刺！」（30 分钟强制结算） |
| 手动暂停 | 用户点按屏幕 | 「已暂停」 |
| 放弃本轮 | 暂停面板「放弃」 | 「本轮已放弃，不计入记录」 |
| 空轮结束 | 一下没跳就结束 | 「这轮没有跳哦，准备好随时再来！」（不落档，回首页） |

### 2.2 记忆与庆祝 ❤️（「它记得住我」）

| 事件 | 触发 | 话术 |
|---|---|---|
| 开场白 | 发令后（当日首轮完整版；同日再轮 1 句短版；「再跳一轮」不播） | **五种版本 × 三句槽位，细则见 §2.5**（本表只占位） |
| 越过昨天 | 第「昨日总数＋1」下（昨日 ≥30，每轮 1 次） | 「超过昨天啦！昨天是 {c} 下」 |
| 破纪录 | 超过历史单轮 PB 的那一下（PB ≥30，每轮 1 次） | 「新纪录诞生！现在每一下都在刷新它！」（fanfare＋金光＋彩带）＋**屏幕闪现 PB 小勋章 icon**（9-2 会议新增 UI：不带具体数字，只示意「破了个纪录」，课后详情页看明细） |
| 目标达成 | 第 1 次到目标 | 「目标达成！继续保持！」（fanfare） |
| 每满环庆祝 | 目标 ×2、×3…（每环 1 次） | 「{c} 下达成！继续冲！」（fanfare） |
| 结算播报（9-2 会议改为**三段式**，分句层层推进、不压在一起，句间停顿 0.5–1s） | 训练停止 | **①快句（端上固定音频，点完成/停止 0 等待即播）**：达标「恭喜你，今日训练已完成！」／未达标「本轮结束，辛苦啦」／超时保存「先帮你把成绩存好啦」 → **②PB 句（仅破了纪录才有；固定素材、不带数字**——课中已判定破的是哪种 PB，按类型取条：单轮/限时/单日/连胜）：「你打破了单次最佳纪录！」 → **③客观小结（可晚 1–2s 到，慢了不尬——用户已在看结果页）**：「今天跳了 {c} 下，用时 {m} 分钟，平均每分钟 {jpm} 下{，比上次快了 {p}%}」——出彩点在**对比**（JPM/越昨/纪录跨度取 1 条），生成走 **LLM＋模板 hybrid**（现有管线，prompt 限句数）或预置模板填槽，**会上留权衡** |
| 纪录跨度 | 破 PB 后点「完成」，恭喜页（旧纪录 ≥2 天） | 「新纪录！上个纪录保持了 {d} 天，被你打破啦」 |
| ⏸ 目标追逐 | 自由跳差目标 10 下 | 「还差 10 下就到目标了！」 |
| ⏸ 断连安慰 | 连击 ≥30 断掉（每轮 ≤2） | 「没关系，重新连起来！」 |
| ⏸ PB 追逐 | 差 PB ≤10 下（每轮 1 次） | 「离你的最高纪录只差 {d} 下，冲！」 |
| ⏸ 热血播报 | 进热血2 / 连击报星 | 「热血全开！保持节奏！」（视觉与音效 V1 保留，语音候补） |

### 2.3 安全与关怀 🛡️

| 事件 | 触发 | 话术 |
|---|---|---|
| 出框 | 人离开画面（**复用 ATOM 系统级出框检测与提示**，V1 不新做；提示语可配则换）→ 自动暂停 | 「回到画面里来，继续！」（安静模式照播） |
| 停跳链 | 见 §4 | 10s：「歇好了吗？我们接着跳！」（开局未起跳：「准备好了就起跳吧！」）；30s 自动暂停：「歇久啦，先帮你暂停，回来点一下继续！」 |
| 长轮关怀 | 自由跳满 20 分钟（每轮 1 次） | 「跳了很久了，注意呼吸节奏」 |
| ⏸ 肯定确认 | 连击稳到 20（每轮 ≤2） | 「对，就是这个节奏！」 |
| ⏸ 节奏轻推 | 明显掉速且已进入状态（每轮 1 次） | 「别停，跟上 ATOM 的节奏！」 |
| ⏸ 交替跳/单脚跳纠错 | 识别到非并脚跳（**9-2 会议拍板要做，需求已向识别侧提出**；端上预留 intent，识别信号就绪即开） | 「请并脚跳，不要交替跳哦」 |
| 🚫 其他姿态纠错 | V2 待识别能力 | 「落地轻一点，缓冲膝盖」等，接口保留 |

### 2.4 设置/工具反馈（不进优先级，即点即播）

补记保存「{日期} 补记 {n} 下」；提醒设置「每天 {t} 提醒你来跳绳」／「提醒已关闭」。

### 2.5 开场白细则（9-2 细拆）

**定位**：整轮唯一一段「成段」的话——教练在开跳瞬间证明「我认识你、我记得你」。铁律三条：**首页阶段零语音**；**3·2·1·Body Park！发令之后才开口**（边跳边听，绝不阻塞开跳）；**总时长 ≤9s，可放宽至 ~12s**（9-2 会议：开场是最值得做 impress 的点——课后用户累了想走，开场每次都能给惊喜；可以多唠两句）。

#### 2.5.1 版本决策（进入训练时按序判断，命中即止）

| # | 版本 | 命中条件 | 结构 |
|---|---|---|---|
| V-E | **不播** | 结算页点「再跳一轮」／安静模式 | — |
| V-A | **新手版** | 从未跳过（无任何历史） | 自我介绍＋日期＋召唤 |
| V-C | **回归版** | 当日首轮 且 断练 ≥3 天 | 回归句＋召唤（回归句情绪足够，不再点名不再报数据） |
| V-B | **常规完整版** | 当日首轮 | 称呼＋第 N 次＋记忆亮点 1 条＋日期＋召唤 |
| V-D | **同日短版** | 今天已跳过 | 1 句（今天已跳 {c} 下：「又来啦！今天已经跳了 {c} 下，这轮继续冲！」；今天进来过但没成绩：「又见面啦！{召唤}」） |

#### 2.5.2 三句槽位与句库（V-B 展开）

**句 1 · 称呼**（~1.5s）——建立「叫得出你名字」：
- 有昵称：「**{昵称}，欢迎回来！**」（音频在设置/修改昵称时一次性云端生成缓存，一个昵称一条）
- 无昵称／clip 未就绪：「欢迎回来！」
- 尾巴（可选，有轮次数据时）：「这是你的第 {n} 次跳绳。」

**句 2 · 记忆亮点**（~2s）——「它记得住我」，四选一，**按轮次轮换**（不随机，保证不同天听到不同的自己）：
1. 连胜（streak >1）：「已经连续打卡 {n} 天啦。」
2. 昨日成绩（昨日 >0）：「昨天跳了 {c} 下。」
3. 单轮 PB（>0）：「你的最好纪录是单轮 {c} 下。」
4. 累计里程碑（>100）：「累计已经跳了 {c} 下。」
一条都不满足（新号第二天等）→ 本句静默，不硬凑。

**句 2.5 · 日期**（~1.5s，可选）：「今天是 {M} 月 {D} 日，」——给每天一个「今天感」，与句 3 连读。

**句 3 · 今日召唤**（~2.5s）——**绑定用户刚选的模式**，收在动员上：
- 自由跳（有目标，4 条池**按日轮换**）：「目标 {g} 下，我们来试一下！」／「今天也来一组 {g} 下吧！」／「向 {g} 下出发！」／「把 {g} 下拿下，开始吧！」
- 自由跳（无目标）：「今天自由跳，我们来试一下！」
- 限时 1′：「一分钟限时，全力冲刺！」；限时 2′：「两分钟限时，稳住节奏冲到底！」

**专属句库**：
- 新手版（V-A）：「欢迎来跳绳！我是 ATOM。今天是 {M} 月 {D} 日，{召唤}」
- 回归版（V-C）：「{d} 天没见啦，回来就好！慢慢找回节奏，{召唤}」

#### 2.5.4 生成、打断与降级

- **生成（9-2 会议校准为现状）**：开场白**已走 LLM＋TTS 管线**（开课 loading 即发请求，321·BodyPark 后播——发令给足了生成时间，实测速度 OK）。prompt 要求：融合历史（昨天/前天、连胜、与历史最佳的对比）＋**留一些不确定性**（每次不一样）＋**落脚点必须是今日小目标**。**禁止隔天预生成**（断练天数/连胜会时效错乱，「你昨天刚练过」变笑话）；如延迟大再做「进 APP 当日预刷两版（自由/限时各一）」。**兜底**：LLM 未就绪 → 端上固定句＋数字拼接版（称呼 clip＋记忆亮点＋召唤），永不空播不等待。
- **打断关系（中档）**：播报期间整十报数（低档）让位丢弃、音效照常；高档事件（越过昨天/破纪录/达标/出框）**随时掐断**开场白且不补播——用户跳得快，庆祝永远比寒暄重要。
- **降级链**：记忆快照缺失 → 句 2 静默（只播 称呼＋日期＋召唤）；昵称 clip 缺失 → 无称呼版；两者全缺 → 「欢迎回来！{召唤}」照样成立——开场白任何一层缺数据都**不空播、不等待、不报错**。
- **防疲劳**：完整版每日一次（`last_greet` 当日去重）；召唤池按日轮换、记忆亮点按轮次轮换——连续来 7 天，7 天听到的开场白都不一样。

#### 2.5.5 生成输入：数据契约与对比维度（9-2 细化）

生成开场白时注入的 `opening_context`（服务端聚合，开课 loading 时随快照下发）：

```json
{
  "nick": "小雨",                          // 可空:没写昵称就不称呼
  "sessions": 17,                          // 历史总轮数(本次=第 18 次)
  "today": "2026-09-02",
  "mode": "free",  "goal": 200,            // free / timed1 / timed2;goal=用户设定档
  "today_count": 0,                        // 今日已跳(>0 → 走同日短版,不进 LLM)
  "days_since_active": 5,                  // 距上次训练天数(1=昨天练过)
  "last_session": { "date": "2026-08-28", "count": 120, "jpm": 104, "mode": "free" },
  "yesterday_count": 0,
  "streak": 0, "max_streak": 6,
  "best_session": 187, "best_at": "2026-08-21",
  "total": 4120
}
```

**对比维度优先级**（prompt 约束模型最多挑 1–2 条，按此顺序命中即用）：

| 序 | 维度 | 条件 | 说法示例 |
|---|---|---|---|
| 1 | 断练间隔 | days_since_active ≥3 | 「5 天没见啦，回来就好！」——回归语气，压过其余一切 |
| 2 | 连胜 | streak ≥2 | 「连续第 6 天来打卡，太稳了！」 |
| 3 | 昨日成绩 | yesterday_count ≥30 | 「昨天 120 下，今天接着涨！」 |
| 4 | 上次成绩 | last_session.count >0 | 「上次跳了 120，这次向 200 出发！」——「上次什么时候练的+练了多少」是最通用的记忆锚 |
| 5 | 接近 PB | last ≥ 0.8×best_session | 「离你的纪录 187 就差一步了！」 |
| 6 | 累计里程碑 | total 刚跨整千 | 「累计破 4000 下啦！」 |

**目标句逻辑**（落脚句，必选）：自由跳以**用户设定档**（50/100/200）为准，措辞可结合上次成绩（上次 120 且目标 200 →「上次 120，今天向 200 出发」；上次已超目标 →「上次都跳到 230 了，200 拿下没悬念！」）；限时用冲刺/耐力语气，可带该时长 PB（「上次一分钟 98，今天试试破 100！」）。⏸ V1.1：智能建议调档（近 3 次平均 ≥ 目标×1.2 时顺嘴一句「可以把目标调到 {下一档} 啦」，每周 ≤1 次，只动嘴不改设置）。

#### 2.5.6 LLM Prompt 模板（可直接落地）

**System prompt**：

```
你是 Body Park 跳绳设备上的元气教练 ATOM，你说的话会通过 TTS 直接播给刚起跳的用户。
任务：根据用户消息里的 JSON 数据，生成一段开场白。

硬规则（违反任何一条即为错误输出）：
1. 只输出要朗读的文本本身——不要解释、引号、emoji、markdown、换行。
2. 2–4 个短句，总字数 ≤60（朗读约 ≤12 秒）。
3. 只使用 JSON 中给出的数据，禁止编造数字或历史；字段缺失或为 0 就绝口不提。
4. 最后一句必须落在今天的目标动员上：mode=free 带上 goal 数字；timed 用冲刺/耐力语气。
5. 记忆点最多挑 1–2 条，优先级：断练≥3天 > 连胜≥2 > 昨日≥30 > 上次成绩 > 接近纪录 > 累计里程碑。
6. 永远不做负面对比（比上次少、断连、退步一律不提）；不提"设备/系统/AI/数据"等字眼。
7. nick 有值就称呼一次，放在最前；为空则不用任何称呼。
8. 数字用阿拉伯数字。
9. 语气元气、亲近、有教练感，最多一个感叹；不油腻、不书面。
10. 措辞每次要有变化，不要固定的开头套路。
```

**User message**：`数据：{opening_context JSON}`

**Few-shot（3 条，附在 system 后）**：
- 断练 5 天、上次 120、目标 200 →「5 天没见啦，回来就好！上次你跳了 120 下，今天咱们慢慢找回节奏，向 200 出发！」
- 连胜 6 天、昨日 150、目标 200 →「小雨，连续第 6 天报到！昨天 150 下状态在线，今天把 200 拿下！」

**输出校验与回落**（端上或服务端任一侧执行）：>80 字 → 截到最后一个句读；出现不在 JSON 值集合中的数字 → 整段丢弃；空/超时（发令后 1.5s 未就绪）→ 回落 §2.5.4 端上拼接版。生成结果 TTS 后按 `hash(opening_context)` 缓存，同日同数据复用。

## 3. 优先级：三档阶梯

V1 不做打分引擎——每句话落三档之一，规则只有三条：

```
高档(可掐断一切):   出框 / 破纪录 / 越过昨天 / 达标·满环 / 时间到 / 30s 自动暂停告知
中档(空闲才播):     开场白 / 结算小结 / 报时 / 30s·10s 节点 / 长轮关怀 / 10s 停跳鼓励
低档(让位即弃):     整十报数(音效照常,只丢人声)
① 同帧取高  ② 高档抢话筒(掐断在播的中低档)  ③ 不排队——让位的句子直接丢弃,默认沉默
```

每轮限次 = 每个事件一个布尔位（Demo 现状写法即最终实现）。打分仲裁引擎、话术表 OTA、48h 记忆去重 → V2（§10）。

## 4. 生命周期：停跳链与暂停/退出边界（9-2 终版）

**停跳链**（人在画面里、未暂停，但绳停了；任何一跳清零重来）：

| 停跳时长 | 动作 |
|---|---|
| 10s | 鼓励一次（每轮 ≤3 次）：「歇好了吗？我们接着跳！」；开局未起跳换「准备好了就起跳吧！」 |
| **30s** | **前端自动进入暂停**＋告知：「歇久啦，先帮你暂停，回来点一下继续！」（暂停遮罩注明「停跳自动暂停 · 点按继续」）。参数可调 30–60s（9-2 会议：嫌短可放 40s/1 分钟）；动因＝持续识别在白耗视频资源＋不暂停显得「对用户无所谓」 |

**暂停生命周期**（三种入口——手动点按 / 出框 / 停跳 30s——之后统一）：

| 情形 | 处理 |
|---|---|
| 恢复 | 停跳计时清零（暂停时长不计入）；继续跳 |
| **暂停超 3 分钟** | **自动结算并保存记录**：「先帮你把成绩存好啦，一共 {c} 下」＋对比句 → 结果页；一下没跳则走空轮保护（不落档回首页） |
| 切后台 / 回 ATOM Home | 立即**静默暂停**（后台绝不出声，声音通道还给系统）；3 分钟内回来接着跳，超时**静默结算保存**，成绩在打卡记录里 |
| 进程被杀 | 课中每 10 下或每 10s 落本地快照；下次启动发现未结算快照 → 补结算，成绩不丢 |
| 限时模式 | 停跳链只保留 10s 鼓励，**不自动暂停**——读秒自己会到、时间到自然结算 |

### 4.1 课中空状态 / 极限状态清单（9-2 盘点）

## 7. 工程实现要点

- **架构**：事件源（每跳回调 / 250ms 看门狗 / 轮次生命周期）→ 查话术配置 → 三档取高 → 播放器（L1/L2/L3 混音）。逻辑树图形版见 Demo 手册「语音播报策略」页签与 `voice-logic-visual.html`。
- **三档实现**：`tier(intent)` 查表；同帧比档位；高档 `tts_stop()` 掐断在播；低档让位即弃。每轮限次 = 布尔位，`session_start` 清零。
- **话术做成配置**（`voice_table.json`：intent → 档位/限次/变体/生成方式），代码只认 intent；V1 可先硬编码，V2 再 OTA。
- **事件接入点对照 Demo**：`registerJump()`（整十/越昨/破纪录/达标/满环）、看门狗（停跳链/报时/限时节点/上限/长轮）、`pauseSession()`（三种暂停）、`endSession()`（小结拼接）、发令后（开场白）、恭喜页（跨度句）。
### 7.1 前端伪代码（设备端，全部离线可算）

```c
/* ---- 三档播放器:整个语音系统唯一的"说话出口" ---- */
enum tier { LOW, MID, HIGH };          /* 低:整十报数 中:开场白/小结/报时/节点 高:庆祝/流程/安全 */
void say(tier t, clip c) {
    if (quiet_mode && !is_system_safety(c)) return;   /* 安静模式只留系统安全句 */
    if (voice_playing && t <= playing_tier) return;   /* 同档/低档让位,直接丢弃不排队 */
    voice_stop();                                     /* 高档掐断在播 */
    voice_play(c); playing_tier = t;                  /* L3 BGM 自动 duck -50% */
}

/* ---- 每跳回调(计数管线) ---- */
void on_jump(int n) {
    sfx(ding[n % 5]); if (n % 10 == 0) sfx(thud);     /* L1 永不缺席 */
    idle_t0 = now(); stall_said = false;              /* 停跳链清零 */
    if (n == snap.yd + 1 && snap.yd >= 30 && !said.yd)      { said.yd = 1; say(HIGH, tpl_yd_pass(snap.yd)); }
    else if (n > snap.pb && snap.pb >= 30 && !said.pb)      { said.pb = 1; sfx(fanfare); say(HIGH, pb_break); }
    else if (goal > 0 && n == goal)                          { sfx(fanfare); say(HIGH, goal_hit); }
    else if (goal > 0 && n > goal && n % goal == 0)          { sfx(fanfare); say(HIGH, tpl_lap(n)); }
    else if (n % 10 == 0)                                    say(LOW, num_clip(n));
}

/* ---- 250ms 看门狗 ---- */
void tick() {
    if (paused || !in_session) return;
    ms idle = count > 0 ? now() - idle_t0 : session_elapsed();
    if (idle > 30s && mode == FREE) { do_pause(BY_IDLE); return; }   /* 30s 无跳动→自动暂停 */
    if (idle > 10s && !stall_said && stall_n < 3)
        { stall_said = true; stall_n++; say(MID, count ? stall_nudge : start_nudge); }
    if (mode == TIMED) {                                             /* 限时:节点+到点结算 */
        if (remain() <= 0)   { settle(false); return; }
        if (remain() <= 10s) once(mark10, say(MID, last10));
        else if (remain() <= 30s) once(mark30, say(MID, last30));
    } else {                                                         /* 自由:上限+报时+关怀 */
        if (elapsed() >= 30min) { settle(true); return; }
        if (elapsed() >= 29min) once(cap, say(MID, cap_soon));
        if (new_minute() && idle < 10s && min != 20 && min < 29) say(MID, tpl_elapsed(min));
        if (elapsed() >= 20min) once(care, say(MID, long_run));
    }
}

/* ---- 暂停生命周期(三入口统一) ---- */
void do_pause(by) {                       /* BY_TAP 手动 / BY_AWAY 出框(系统级) / BY_IDLE 停跳30s */
    pause_clock();
    say(by == BY_TAP ? MID : HIGH, pause_line(by));      /* 后台切出:静默,不 say */
    after(3min, () => settle_or_zero(saved = true));     /* 超时:停止并保存 */
}
void on_resume()     { idle_t0 = now(); cancel(3min_timer); }
void on_background() { do_pause(SILENT); }               /* 声音通道还给系统 */
/* 崩溃兜底:每 10 下或每 10s 落快照;启动时发现未结算快照 → 补结算 */

/* ---- 结算三段式(9-2 会议版):分句层层推进,句间停顿 0.5–1s ---- */
void settle(bool saved_by_timeout) {
    if (count == 0) { say(MID, zero_round); go_home(); return; }     /* 空轮保护 */
    sfx(settle_chord);
    /* ① 快句:端上固定音频,0 等待 */
    say(MID, saved_by_timeout ? saved_line : goal_met ? done_congrats : done_plain);
    /* ② PB 句:仅破了纪录才有;固定素材不带数字,课中已知破的是哪种 PB */
    if (pb_broken_kinds) after(0.8s, () => say(MID, pb_line(pb_broken_kinds[0])));
    /* ③ 客观小结:LLM+模板 hybrid,可晚 1–2s 到(用户已在看结果页,慢了不尬);
       内容 = 下数/用时/JPM + 1 条对比(JPM 提升/越昨/纪录跨度);失败回落模板填槽版 */
    request_summary(count, elapsed, jpm(), snap, (text) => say(MID, text));
    persist_round();                                     /* 含 best_at / jpm 更新 */
    if (new_pb) pending_cele = true;                     /* 恭喜页在点「完成」后 */
}
void on_finish_tap() { if (pending_cele) { cele_show(); say(HIGH, span_days >= 2 ? tpl_span(span_days) : new_rec); } }

/* ---- 开场白(§2.5 决策表直译) ---- */
void opening() {
    if (again_tap || quiet_mode) return;                        /* V-E */
    if (no_history)               { say(MID, hello_new + date + call()); return; }   /* V-A */
    if (first_today && snap.days_since_active >= 3)
                                  { say(MID, tpl_return(snap.days_since_active) + call()); return; }  /* V-C */
    if (!first_today)             { say(MID, today_count ? tpl_again(today_count) : back + call()); return; } /* V-D */
    clip who = snap.nick_clip ? snap.nick_clip : welcome_plain;  /* V-B:缺哪层砍哪层 */
    clip hl  = pick_rotate(streak_line, yd_line, pb_line, total_line);   /* 可为空 */
    say(MID, who + nth(sessions) + hl + date + call());
}
```

### 7.2 后端伪代码（只有三件慢事）

```python
# ① 记忆快照:开轮前拉取(端上缓存,离线用上一份)
def memory_snapshot(user):
    h = history(user)
    yd = h.get(today() - 1)
    return {
        "yesterday_count": max(0, yd.count - yd.manual) if yd else 0,   # 对比只用实测(待定确认)

    }

# ② 昵称音频:设置/修改昵称时一次性生成(没有每日管线)
def on_nick_change(user, nick):
    audio = tts(f"{nick}，欢迎回来！", voice="coach_v1")   # 失败静默,端上回落无称呼版
    return store_clip(user, audio)

# ③ 结算落档(既有训练上报里顺带维护语音所需字段)
def on_session_end(user, r):          # r = {count, ms, mode, started_at, manual=0}
    d = date(r.started_at)            # 跨天轮按开轮日期(待定确认)
    day = history(user).setdefault(d, Day())
    day.count += r.count; day.best = max(day.best, r.count); day.ms += r.ms
    if r.count > user.best_session:
        user.best_session, user.best_at = r.count, d      # best_at 支撑"纪录跨度"句
    update_streak(user, d)            # 既有逻辑不变
# 语音包 OTA = 静态资源分发,走既有通道;快照/昵称接口失败时端上按 §2.5.4 降级,永不阻塞
```
