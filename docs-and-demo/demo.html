关键点接口(AI 管线 → 渲染)

接口说明
feedPose(pts[33])MediaPipe Pose 拓扑,归一化 0–1、原点左上、喂入前完成镜像,≥15Hz;500ms 无数据回落内置模拟。渲染实际使用 13 点:耳 7/8 · 肩 11/12 · 肘 13/14 · 腕 15/16 · 髋 23/24 · 膝 25/26 · 踝 27/28
onJump()AI 判定一次有效跳跃 → 计数+1,同帧触发数字打击/涟漪/发光/音效。计数管线独立,骨骼流只负责渲染
setPresence(bool)仅用于训练中暂停/恢复,不作为开跳门槛
视口变换整帧固定缩至 2/3、底边锚 0.94(顶部 1/3 永久让给数字):x'=0.5+(x−0.5)×⅔ · y'=0.94−(1−y)×⅔
完整文档:figure-rendering.md;规格卡:ui/figure-spec.png

训练屏节奏(课中反馈引擎)

节拍反馈
每一跳五声音阶"叮" + 数字砸入回弹 + 脚下金色透视涟漪(同帧,延迟 <100ms)
每 10 下数字重击(1.9×+震屏)+ 火柴人全身金光 0.5s + 语音报数 + 50% 概率小彩带
每 20 下+2★ 飞星;15% 概率彩蛋双倍 +4★ + 彩带雨(唯一常规 toast)
每 50 下得一颗 ★(全模式统一,与环解耦)+ 燃起来火焰升级 + 换绳色 + 语音报星
隐藏数字每天 55–99 换一个,踩中 +5★ + 彩带 + 专属播报
达标彩带 + 数字转暖 + "继续冲!"——绝不打断,51、52 继续数
随时超越对手即时播报;整 30 语音 = 鼓励/纠错指导五五开;节奏掉 60% 轻推(每轮一次)
Toast 纪律:常规节点全语音化不弹层;toast 仅限稀有事件(彩蛋双倍/隐藏数字/达标/超越/休息提醒)。

进度环与星星

环(目标/自由)一圈 = 一个目标(自由跳 50),跳满清零重画
环(限时)60 格时间刻度环:每格=总时长/60(1'=1s/格),逢五长刻度;剩余=亮格从尾端逐格熄灭,最后 10s 转暖橙
星星 ★固定每 50 一颗(荣誉刻度,全模式统一,不入账);>4 颗收敛为 ★×N
货币星整20 +2 / 彩蛋 ×2 / 隐藏数字 +5 / 达标 +10 → 结算入账,消耗于换装/场景/补签卡

开场白(进入 APP 时播,模块化拼装)

状态与超时策略(空 / 边界 / 极限)

计数累积单轮从 0 起算;今日累计跨轮累加(首页/榜单/结算"今日累计"行),0 点重置;结算即落档
离开画面/切后台训练中立即暂停(停表)→ 超 3 分钟未回自动结算(对齐课程出框策略,可配 3–5min);结算页 45s 无操作回首页
极限保护自由跳单轮上限 15 分钟(最后 1 分钟语音预告,届满自动结算);计数 ≥1000 数字降档 96→68;单日封顶 3000(服务端)
空状态首页真实零值 + 引导文案;榜单未跳也有真实名次与"再跳 N 下超过 XX"

排行榜(可爬升设计 · 2026-08-17 评审会定稿)

三榜:今日单轮最高(0 点重置;当日累计不上榜,防刷)· 1 分钟测试(历史最佳;限时时长各自成榜)· 连胜。全员默认参与,无退出项;同分按显示名首字母排;未填昵称显示邮箱/手机脱敏前缀(如 rop***),开场白语音不点名。只显示 Top3 + 我的邻近区间,脚注永远给"再跳 N 下超过 XX",课中超越即时播报,进前三/登顶语音。

AI 管线接口(C / WebView 通用契约)

on_eventsession_start{mode} · jump{count} · session_end{count, ms, goal, testMin, kcal, newBest}(ms=净时长,暂停不计)
