## 0. 一句话原则

**声音是这个产品的"第二块屏"。** 466 圆屏在 1–2 米外、用户全程"手里有绳"看不清小字——反馈的主通道是耳朵。因此：**计数音效永远第一优先**（它是"这一下算了"的唯一即时确认），人声其次，BGM 永远垫底；一切声音**短、低频、可关**，宁可少说不可打扰节奏。

## 1. 三层音频架构

| 层 | 内容 | 相对音量 | 打断关系 | 可关 |
|---|---|---|---|---|
| **L1 音效 SFX** | 计数叮 / 逢十重击 / 得星 / 倒计时哔 / 发令 / fanfare / 彩蛋 | 100%（基准） | 永不被打断，可与任意层叠放 | 不可单独关（关语音后仍保留——它是计数确认） |
| **L2 TTS 人声** | 报数 / 激励 / 指导 / 事件播报 / 流程语音 | ≈90% | 高优先级可打断低优先级（§4） | 可关（设置「教练语音」） |
| **L3 BGM** | 轻量节奏循环 | ≈25%，人声播报时 duck 到 12%（-50%） | 永不打断任何层 | 可关（设置「背景音乐」） |

混音要求：三通道独立增益；L2 说话时 L3 自动闪避（attack 80ms / release 400ms）；L1 不参与闪避。计数音效从 `onJump` 判定到出声 **< 100ms**（PRD §7 反馈延迟同帧要求）。

## 2. L1 音效包（新制，不复用课程音效——08-17 决议）

设计语言：**五声音阶（C 宫：C-D-E-G-A）统一调式**，BGM 同调式，任何叠放都不刺耳。全部为 ≤400ms 的干声短样本，预烘焙进固件资产包。

| id | 触发 | 时长 | 设计意图 | 与视觉同帧 |
|---|---|---|---|---|
| `sfx_jump` | 每次有效计数 | ~80ms | 五声音阶循环叮声（连跳时音高沿 C-D-E-G-A 步进，天然"越跳越high"） | 数字砸入动画 |
| `sfx_jump_heavy` | 逢十计数 | ~150ms | 重击版（低八度加厚），与数字重击帧同拍 | 重击闪 + 金光 |
| `sfx_star` | 每满 50 得星 / 彩蛋 / 隐藏数字 | ~300ms | 上行琶音"叮铃"，奖励感 | 星星飞入 |
| `sfx_beep` | 倒计时 3·2·1 | ~120ms×3 | 干净短哔，最后一声可微升调 | 136px 大数字 |
| `sfx_go` | BodyPark 发令帧 | ~400ms | 有冲劲的上扬音（品牌声纹候选位） | 发令帧 0.75s |
| `sfx_fanfare` | 破纪录 / 达标 / 恭喜页 | ~600ms | 小号式短号角（全包里唯一"隆重"的一条） | 彩带 + 金光 |
| `sfx_timeup` | 限时到点 | ~400ms | 收束感下行双音 | 刻度环熄灭 |
| `sfx_tick_warn` | 限时最后 10s（可选逐秒） | ~60ms | 极轻的秒针声（待定：可能太吵，A/B） | 环转暖橙 |
| `sfx_tap` | 界面点按 | ~40ms | 极轻确认声 | — |

> 交付：设计侧出 9 条干声（48k/16bit 源，端上转 opus/pcm）；总资产预算 < 300KB。Demo 现用 WebAudio 合成版可作为**节奏与音高关系的听感 spec**直接参考。

## 3. L3 BGM

- **形态**：110BPM、8/16 小节无缝循环、五声音阶低音+轻打击，无旋律主线（不与人声抢频段，300Hz-2kHz 留给 TTS）。
- **随"燃起来"分层升级**（与视觉火焰同拍）：基础层（0–49 下）→ +轻鼓组（50）→ +低音线（100）→ +高帽/energy（150+，封顶）。实现＝同一循环的 3 条 stem 叠放，无需切歌。
- **生命周期**：3·2·1 倒计时不放；发令帧起播；暂停即静音（不是降音量）；结算页停止；恭喜页不放 BGM 只放 fanfare。
- **闪避**：见 §1；连续播报（如整十连报）之间 <1s 不恢复，避免音量"呼吸"。
- 待定（§9-Q2）：是否做**跳频自适应 tempo**（绳速快 BGM 加速）——爽感强但工程复杂，倾向 P1 再试。

## 4. L2 TTS 人声：内容分类与优先级仲裁

### 4.1 优先级（同帧多事件只播最高优，低优直接丢弃不排队）

```
P0 破纪录事件（spPbBreak）
P1 达标 / 时间到 / 恭喜（spGoal / spTestEnd / 新纪录收官）
P2 满圈报星（每 50） / PB 追逐（差 ≤10）
P3 整三十激励·指导 / 超越播报 / 彩蛋
P4 整十报数
P5 趣味彩蛋（随机低频闲聊）
```

- 正在播 P3/P4/P5 时来了 P0/P1 → **打断**；反向永不打断。
- 同优先级后到丢弃（不排队——排队会导致"事件过去了才说"）。
- toast 与语音分工维持现行：常规节点全语音化不弹 toast，toast 只留稀有事件（破纪录/彩蛋双倍/隐藏数字/达标/上限预告）。

### 4.2 内容六类（跳绳专属语音库——8-18 决议）

| 类 | 内容 | 触发/频控 | 生成方式 |
|---|---|---|---|
| A 计数播报 | "五十！""一百二十！" | 整十；被 B/C/D 占用时让位 | **预生成拼接**（数字素材 0–9/十/百，~40 条覆盖 0–999，见 §9-Q3） |
| B 节点激励 | 加油池 7 条 + 指导池 6 条（膝盖微弯/前脚掌/手腕发力/目视前方/呼吸/并脚） | 整三十，鼓励/指导五五开；同条 ≥2 轮不重复 | 预生成 |
| C 动作纠错 | "双脚并拢跳""光线暗一点" | formHint（V1 暂不启用，接口保留）；同类 ≥20s | 预生成 |
| D 事件播报 | 破纪录/差 N 下破纪录/达标/超越 XX/进前三/彩蛋/隐藏数字 | 事件即时；PB 追逐每轮一次 | 模板+数字拼接 或 TTS |
| E 流程语音 | 倒计时三·二·一·BodyPark / 30s·10s 节点 / 上限预告 / 收尾总结 / 空轮轻语音 / 暂停·继续 | 固定节点 | 预生成 |
| F 趣味彩蛋 | 低频闲聊梗（"Bono 快跟不上啦""月亮都出来看你跳绳了"），降低长时间运动枯燥感（8-18） | 自由跳 >3 分钟后启用，~90s 一次触发窗、35% 概率、每轮 ≤3 条；池 ≥20 条按日轮换 | 预生成 |

### 4.3 生成方式分界（预生成语音包 vs 动态 TTS）

- **预生成**（固件资产包，双语双份）：A/B/C/E/F 全部 + D 的固定句式——高频、低延迟（<100ms 出声）、离线可用、音色 100% 一致。
- **动态 TTS**（云端合成，可缓存）：开场白拼装（点 Start 后）、结算总结（含成绩数字）、榜单播报（含对手昵称——**必须 TTS**，昵称不可枚举）。弱网降级：TTS 失败 → 播对应的无变量兜底句（如"新纪录！"替代"132 下，新纪录！"）。
- 数字规则见 §9-Q3。

### 4.4 频控与防疲劳（汇总）

| 规则 | 值 |
|---|---|
| 整十报数 | 每 10 下一次（≤3 字，最短句） |
| 整三十激励/指导 | 五五开随机，同条本轮不重复 |
| 满圈报星 | 每 50 一次（压过整十） |
| PB 追逐播报 | 每轮 ≤1 次（差 ≤10 时） |
| 节奏轻推 | 每轮 ≤1 次（慢 60%+） |
| 纠错同类 | ≥20s 间隔（启用后） |
| 趣味彩蛋 | 3 分钟后启用，~90s 窗口 35%，每轮 ≤3 |
| 超越播报 | 仅前 15 名内逐位、进前三/登顶才用人声 |

## 5. 课中时间轴（自由跳 · goal 200 示例）

| 时刻/事件 | 层 | 内容 |
|---|---|---|
| 点 Start（模式页） | L2-E | 开场白（当日首次）或模式提示；**首页阶段零语音** |
| 选模式 | L1 | `sfx_tap` |
| 倒计时 | L1+L2 | `sfx_beep`×3 + "三·二·一" |
| 发令 | L1+L2+L3 | `sfx_go` + "Body Park!"；BGM 起 |
| 每跳 | L1 | `sfx_jump`（音高步进） |
| 整 10 | L1+L2 | `sfx_jump_heavy` + 报数（P4） |
| 整 30 | L2 | 激励/指导五五开（P3，顶掉本次报数） |
| 整 50 | L1+L2 | `sfx_star` + "五十下，点亮第一颗星！"（P2）；BGM +1 层 |
| 差 PB ≤10 | L2 | "离你的最高纪录只差 N 下，冲！"（P2，一次） |
| 破 PB | L1+L2 | `sfx_fanfare` + "新纪录诞生！"（P0，打断一切） |
| 200 达标 | L1+L2 | `sfx_fanfare` + "目标达成！继续保持！"（P1）；环重置、BGM 保持最高层 |
| >3min 起 | L2-F | 趣味彩蛋窗口开启 |
| 29min | L2-E | "还有一分钟到三十分钟上限，冲刺！" |
| 暂停/继续 | L2-E | "已暂停"；BGM 静音 |
| 结算 | L2-E | 收尾总结（TTS 含数字）；BGM 停 |
| 点「完成」·新纪录 | L1 | 恭喜页 `sfx_fanfare`（不再叠人声，结算已总结过） |

限时 1'/2' 差分：+30s/10s 节点（"还有三十秒"/"最后十秒，冲刺！"）、最后 10s 可选 `sfx_tick_warn`、时间到 `sfx_timeup` + 总结（1' 含体测评级播报）。

## 6. 音色与人设（开放——§9-Q1）

- 人设锚点：**Bono 的声音**——有活力、亲和、不"幼儿向"（主用户 6–17 岁 + 成人家庭，声音太低龄会劝退大孩子和家长）。
- 候选方向：① 单一音色"元气教练"（青年声，全用户）② 双音色按年龄段（儿童账号=活泼版 / 成人=沉稳版）③ 先单一后扩展。
- 双语：zh/en 同一人设两套录音/音色；EN 不做中式口音梗。
- 品牌声纹："Body Park!" 发令词值得单独精调（全产品可复用的 audio logo）。

## 7. 设置与可关性

- 「教练语音」关 = 关 L2 全部（含报数）；L1 音效保留（计数确认不可失去）。
- 「背景音乐」关 = 关 L3。
- 待定（§9-Q4）：是否加**安静模式**快捷档（= 语音关+BGM 关，只留 L1，夜间/公共场景一键切）。

## 8. 工程落地

- 资产：SFX 9 条（<300KB）+ 预生成语音包（估 A~40 + B 13 + C 4 + E ~15 + F 20 ≈ 92 条/语言，opus 24kbps ≈ 1.5–2MB/语言）。
- 端上：3 通道混音 + ducking + 优先级仲裁器（打断=立即停止当前 L2 源）；Demo 的 `speak()` 单通道行为即仲裁器退化版。
- TTS 引擎/供应商：待定（§9-Q5）；开场白与结算总结可**预取**（进结算前 500ms 内容已知）。
- 验收：计数音效延迟 <100ms；ducking 无爆音；任意 15 分钟连跳语音不重复感知（B/F 池轮换验证）。
