关键点接口(AI 管线 → 渲染)

接口说明
feedPose(pts[33])MediaPipe Pose 拓扑,归一化 0–1、原点左上、喂入前完成镜像,≥15Hz;500ms 无数据回落内置模拟。渲染实际使用 13 点:耳 7/8 · 肩 11/12 · 肘 13/14 · 腕 15/16 · 髋 23/24 · 膝 25/26 · 踝 27/28
onJump()AI 判定一次有效跳跃 → 计数+1,同帧触发数字打击/涟漪/发光/音效。计数管线独立,骨骼流只负责渲染
setPresence(bool)仅用于训练中暂停/恢复,不作为开跳门槛
视口变换整帧固定缩至 2/3、底边锚 0.94(顶部 1/3 永久让给数字):x'=0.5+(x−0.5)×⅔ · y'=0.94−(1−y)×⅔
完整文档:figure-rendering.md;规格卡 PNG:ui/figure-spec.png;伴随动效(绳/涟漪/发光)细节同文档 §5。

训练屏节奏(课中反馈引擎)

节拍反馈
每一跳五声音阶"叮" + 数字砸入回弹 + 脚下金色透视涟漪(同帧,延迟 <100ms)
每 10 下数字重击(1.9×+震屏) + 火柴人全身金光 0.5s + 语音报数 + 50% 概率小彩带
每 20 下+2★ 飞星;15% 概率彩蛋双倍 +4★ + 彩带雨(唯一常规 toast)
每 50 下得一颗 ★(全模式统一,与环解耦)+ 燃起来火焰升级 + 换绳色 + 语音报星
隐藏数字每天 55–99 换一个,踩中 +5★ + 彩带 + 专属播报
达标彩带 + 数字转暖 + "继续冲!"——绝不打断,51、52 继续数
随时超越榜上对手即时播报;整 30 语音 = 鼓励/纠错指导五五开;节奏掉 60% 轻推(每轮一次)
Toast 纪律:常规节点全语音化不弹层;toast 仅限稀有事件(彩蛋双倍/隐藏数字/达标/超越/休息提醒)。

进度环与星星

环(目标/自由)一圈 = 一个目标(自由跳 50),跳满清零重画

状态与超时策略(空 / 边界 / 极限)

计数累积单轮从 0 起算(一轮一个目标);今日累计跨轮累加(首页/榜单/结算"今日累计"行),0 点重置;结算即落档
