# Body Park · 跳绳小挑战（Jump Rope Mini Challenge）

**打开就能跳的摄像头跳绳小应用** —— Atom 智能设备(466×466 圆屏 @10–15fps + 摄像头 + 后端 AI 姿态/计数管线)。
核心诉求:简单易上手,不用动脑,打开就能用。

当前版本:**proto-v0.28**(2026-08-14)· Atom 端(手机端暂缓)。

## 产品速览

- **流程**:入口卡(个性化开场白)→ 首页卡组(首页/打卡记录/全球排行)→ 模式选择(限时 1'/2' · 不限时)→ 3·2·1·**BodyPark** 即时开跳 → 训练 → 庆祝(达标不打断)→ 结算⇄二维码分享
- **训练屏**:进度环(限时=60 格刻度环)+ 打击计数(逢十重击+全身金光)+ 骨骼火柴人 + 随机彩绳(8 色池,每 50 换色)+ 金色涟漪 + 每 50 得星/燃起来
- **激励**:连胜打卡 + 每日重置排行榜(实时超越)+ 星星/隐藏数字/场景解锁;常规节点全语音化;教练语音含纠错指导
- **硬约束**:字号 6 档(18/22/24/28/32/36)、黑白灰绿品牌色、单色 SVG 图标、10–15fps 离散帧、中英双语
