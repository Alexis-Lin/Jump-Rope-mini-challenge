# Jump Rope Mini Challenge

Body Park 跳绳小挑战 —— 打开就能跳的摄像头跳绳小应用（Atom 智能设备优先，手机 App 暂缓）。

## 当前过程版本：proto-v0.5（2026-08-07）

**Atom 端（466×466 圆屏 @15fps）完整闭环**，39 次迭代提交：

- **信息架构**：系统入口卡 → 三卡首页（首页卡 / 历史·排行榜入口卡 / 成就卡）→ 模式选择（限时跳 1'/2' · 不限时每日任务）→ 训练 → 庆祝 → 结算（翻面分享海报+二维码）；二级页：历史打卡、排行榜（全球/同城）、勋章墙、设置
- **训练屏**：贴边进度环（一圈=一目标）→ 顶点计时 → 上 1/3 格斗游戏式打击数字（逢十重击）→ 下 2/3 固定视口实时骨骼火柴人（`AtomSkeleton.feed()` 33 点接口 + 内置漫游模拟）→ 计数同步的金闪涟漪
- **玩法与激励**：达标不打断持续计数、每 50 一星、燃起来三级火焰（黑底暖色）、每日隐藏数字、连胜/勋章/星星/每日重置排行榜（实时超越播报）、体测评级（年龄段）、卡路里估算（MET）、AI 教练语音分层播报、每日新鲜感（月相/文案/场景轮换）
- **品牌**：黑白灰绿 + 打击金；等宽直杆火柴人（白身白头、手脚圆头）；单色 SVG 图标；15fps 动效量化（可切 60fps 对比）
