# Body Park · 跳绳小挑战（Jump Rope Mini Challenge）

**打开就能跳的摄像头跳绳小应用** —— Atom 智能设备(466×466 圆屏 @10–15fps + 摄像头 + 后端 AI 姿态/计数管线)。
核心诉求:简单易上手,不用动脑,打开就能用。

当前版本:**proto-v0.27**(2026-08-14)· Atom 端(手机端暂缓)。

## 产品形态速览

- **信息架构**:系统入口卡(个性化开场白)→ 首页卡组(首页 / 打卡记录 / 全球排行,横滑)→ 模式选择(限时跳 1'/2' · 不限时每日任务)→ 3·2·1·**BodyPark** 即时开跳 → 训练 → 庆祝(达标不打断)→ 结算(成绩⇄二维码分享);二级页:打卡记录 / 排行榜 / 最佳战绩 / 设置
- **训练屏**:进度环(一圈=一目标;限时模式为 60 格时间刻度环)+ 打击计数(逢十重击+全身金光)+ 实时骨骼火柴人 + 随机彩色虚拟绳(8 色池,每 50 换色)+ 计数同帧金色涟漪 + 每 50 得星/燃起来三级火焰
- **激励**:连胜打卡 + 每日 0 点重置排行榜(实时超越播报)+ 星星/隐藏数字/场景解锁;常规节点全语音化(toast 仅稀有事件);教练语音含纠错指导与节奏轻推
- **硬约束**:字号 6 档标准(18/22/24/28/32/36)、黑白灰绿品牌色、单色 SVG 图标、10–15fps 离散帧动效、中英双语字典
- **状态策略**:单轮从 0 / 今日累计跨轮累加;离开画面暂停 5s 自动结算;30min 休息提醒 / 60min 强制结算;详见 PRD §6
